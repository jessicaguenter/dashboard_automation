# Automated Reporting Dashboard

**Author:** [@Rynk-Dev](https://github.com/Rynk-Dev)

## Overview

This project contains files that pull from the HubSpot and QuickBooks API to dynamically populate the reporting dashboard. 

## Setup Note

> This project will not run in its current form.

> To succesfully execute the scripts, you must configure:
> **OAuth2 Extension**
> & **API Credentials**
